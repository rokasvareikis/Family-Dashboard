Dashboard settings

On each iPhone: Calendar app → Calendars → ⓘ next to the calendar → turn on Public Calendar → Share Link → send yourself the link (starts with webcal://). Paste it above. Anyone with the link can read that calendar, so share only calendars you're happy to expose.
iCloud doesn't allow browsers to fetch calendars directly. Deploy the small proxy in worker.js and paste its address ending in ?url= here.
